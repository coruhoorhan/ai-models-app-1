## 2025-02-28 - Optimize LLM Chat Message Rendering
**Learning:** During active LLM token streaming in chat interfaces, parent state updates happen very rapidly (on every chunk). The `ChatMessageItem` component was not wrapped in `React.memo`, leading to expensive, redundant re-renders of all previous messages in the list upon each new chunk.
**Action:** Always wrap list items in `React.memo` (e.g., `export const Item = React.memo(...)`) for chat histories or other lists where the parent is subject to high-frequency streaming state updates and the list items themselves rarely change reference.## 2024-05-24 - Expensive Component Re-renders\n**Learning:** Recharts charts (like AreaChart) and heavy Framer Motion trees (like PodiumCard) can trigger expensive re-renders when parent components update state unrelated to their props (e.g., URL parameters, global state). The `React.memo` optimization only works efficiently when props passed to these heavy components remain referentially equal, or are primitive.\n**Action:** Always wrap heavy visual components in `React.memo` and ensure that the props passed to them from the parent are referentially stable, especially in data-heavy dashboard or ranking views.
