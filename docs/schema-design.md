# Database Schema Design

This document details the database schema for the application, aligning with the visual requirements outlined in `PAGES.md` and performance standards in `ENGINEERING-STANDARDS.md`.

## Architectural Decisions & Assumptions

*   **Database:** PostgreSQL
*   **Hosting Provider:** Neon.
    *   *Rationale:* Neon offers a serverless PostgreSQL architecture with branch-based database environments. This perfectly complements our Prisma workflow and Git branching strategy, allowing us to spin up isolated database copies for every PR automatically. Since we are implementing our own HTTP-Only Cookie JWT auth (as defined in our API contract) rather than relying on a third-party Auth-as-a-Service like Supabase Auth, Neon provides exactly the flexible, pure Postgres foundation we need without imposing external ecosystem constraints. It also has a generous free tier for our early stages.
*   **ORM:** Prisma
*   **Performance Pattern:** Materialized fields are used for frequently accessed computed data.
    *   `users.current_balance`: Updated via a database transaction whenever a new record is added to `billing_transactions` or `usage_logs` to avoid expensive aggregations on reads.
    *   `rankings.weekly_change`: Updated via a background cron job.

## Entity Definitions

### 1. `users`
Stores user authentication, subscription, and cached billing information.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `email` | String | Unique, Not Null | User email. |
| `password_hash` | String | Not Null | Hashed password. |
| `username` | String | Not Null | Display name used in dashboard ("Good afternoon, [username]"). |
| `subscription_tier` | Enum | Not Null, Default: 'Free' | Replaces `users.plan` from PAGES.md. Enum: `Free`, `Pro`, `Enterprise`. |
| `current_balance` | Decimal | Not Null, Default: 0 | Materialized sum of billing_transactions - usage_costs. |
| `created_at` | DateTime | Default: NOW() | Creation timestamp. |
| `updated_at` | DateTime | Updated automatically | Last update timestamp. |

### 2. `api_keys`
Manages API keys generated by users.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `user_id` | UUID | Foreign Key -> `users.id` | The user who owns this key. |
| `key_hash` | String | Unique, Not Null | Securely hashed representation of the API key. |
| `name` | String | Not Null | User-defined name for the key. |
| `last_used_at` | DateTime | Nullable | Tracks when the key was last invoked. |
| `expires_at` | DateTime | Nullable | Optional expiration date. |
| `created_at` | DateTime | Default: NOW() | Creation timestamp. |

### 3. `providers`
Lookup table for model providers (e.g., OpenAI, Anthropic, Google).

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `name` | String | Unique, Not Null | Provider name. |
| `created_at` | DateTime | Default: NOW() | Creation timestamp. |

### 4. `models`
Catalog of AI models available in the system.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `provider_id` | UUID | Foreign Key -> `providers.id` | The provider offering this model. |
| `name` | String | Not Null | Display name of the model. |
| `context_size` | Int | Not Null | Context window size (e.g., 128000). |
| `price_per_1m` | Decimal | Not Null | Cost per 1 million tokens. |
| `speed_tok_s` | Int | Not Null | Average processing speed in tokens per second. |
| `is_free` | Boolean | Default: false | Indicates if the model is available on the free tier. |
| `category` | Enum | Nullable | Maps to `badge-category`. Enum: `Coding`, `Chat`, `Character`. |
| `created_at` | DateTime | Default: NOW() | Creation timestamp. |

### 5. `usage_logs`
Records every API invocation.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `user_id` | UUID | Foreign Key -> `users.id` | The user who made the request. |
| `model_id` | UUID | Foreign Key -> `models.id` | The model used. |
| `api_key_id` | UUID | Foreign Key -> `api_keys.id` | The API key utilized. |
| `tokens_in` | Int | Not Null | Prompt tokens consumed. |
| `tokens_out` | Int | Not Null | Completion tokens generated. |
| `cost` | Decimal | Not Null | Calculated cost of the request. |
| `duration_ms` | Int | Not Null | Total processing time. |
| `created_at` | DateTime | Default: NOW() | Timestamp of the request. |

**Indexes:**
*   Composite Index on `(user_id, created_at)`: Critical for efficient time-series aggregations on the Dashboard charts.

### 6. `billing_transactions`
Ledger of user financial activities (top-ups, subscriptions).

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `user_id` | UUID | Foreign Key -> `users.id` | The associated user. |
| `amount` | Decimal | Not Null | Transaction amount. |
| `transaction_type` | Enum | Not Null | Enum: `TopUp`, `Spend`, `Subscription`. |
| `created_at` | DateTime | Default: NOW() | Timestamp of the transaction. |

### 7. `rankings`
Stores leaderboard data for models.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `model_id` | UUID | Foreign Key -> `models.id` | The ranked model. |
| `rank` | Int | Not Null | Current leaderboard position. |
| `score` | Int | Not Null | Aggregate benchmark score. |
| `speed_viz` | Int | Not Null | Normalized visual representation score of speed. |
| `weekly_change` | Int | Default: 0 | Pre-calculated delta vs last week (materialized by cron). |
| `created_at` | DateTime | Default: NOW() | Record creation/snapshot timestamp. |

### 8. `chat_sessions`
Metadata for Built-in Chat feature.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `user_id` | UUID | Foreign Key -> `users.id` | Owner of the chat. |
| `title` | String | Not Null | Auto-generated or user-defined title. |
| `created_at` | DateTime | Default: NOW() | Session start timestamp. |

### 9. `chat_messages`
Individual messages within a chat session.

| Field Name | Type | Modifiers | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique identifier. |
| `session_id` | UUID | Foreign Key -> `chat_sessions.id` | Associated session. |
| `sender` | Enum | Not Null | Enum: `User`, `Bot`. |
| `content` | Text | Not Null | Markdown or raw text content. |
| `tokens_used` | Int | Nullable | Token cost for bot messages. |
| `created_at` | DateTime | Default: NOW() | Message timestamp. |
